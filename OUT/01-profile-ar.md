# البروفايل المهني — صهيب عسراوي

> مصدر كل سطر هنا: حزمة Master Brain المصدَّرة بتاريخ 2026-09-14 (التقارير + عقول المشاريع + سجلّات التقدّم) وملف القدرات الداخلي. لا أرقام ولا عملاء مخترَعون.

## العنوان الوظيفي المقترح

**مهندس برمجيات وقائد تسليم رقمي يعمل بوكلاء الذكاء الاصطناعي**  
*Software Engineer · AI-Agent-Driven Delivery Lead*

بديل أقصر للمنصّات الحرّة: **مهندس برمجيات — منصات ويب عربية (Next.js / Laravel) وأتمتة بوكلاء AI**

## النبذة

مهندس برمجيات أردني بخبرة مؤسسية طويلة في Java وC# وSQL (أنظمة بنكية، حضور ودخول، إدارة طوابير)، انتقل في 2026 إلى نموذج عمل جديد: يقود **محفظة من 46 مشروعاً** عبر وكلاء برمجية (Cursor، Claude Code، Codex، ChatGPT) من منصة متابعة بناها بنفسه اسمها **Master Brain**، لكل مشروع فيها «عقل هندسي» يسجّل المنجز والجاري والتالي والقيود.  
خلال أسبوع واحد (10–14 أيلول 2026) وصلت خمسة مشاريع إلى الإنتاج أو ما يقاربه: منصة ذكاء تجاري بحلقة محاكاة كاملة، مواقع مصانع أردنية منشورة على Vercel، أدوار مشاهير على منصة ريشة 360 في الإنتاج، متجر تجريبي فاخر، وأكاديمية ذكاء اصطناعي صناعي لـ GIZ.  
ما يميّزه ليس لغة بعينها بل **الانضباط**: كل مشروع له قيود مكتوبة (لا شراء حيّ، لا نشر بلا إذن، لا أرقام مخترَعة)، وكل تقدّم له دليل (اختبارات خضراء، commit، رابط نشر).

## المهارات (مرتّبة حسب قوة الدليل)

### 1. تسليم منصات ويب عربية ثنائية اللغة — دليل قوي
- **Next.js** (حتى الإصدار 16) مع RTL/LTR، سمات فاتحة/داكنة، i18n — في 6 مشاريع منشورة.
- **Laravel + Filament** (ريشة 360: أدوار، ترحيلات، آلة حالة للصرف، اختبارات PHPUnit؛ خذني: Filament + SQLite).
- **PostgreSQL / Prisma** (Project1: persistence + locks)، **Supabase + RLS** (براءة الشوبكي).
- نشر على **Vercel** و**Laravel Forge** مع PR وmigrate وpm2.

### 2. بناء أدوات ومنصات تشغيل بلا اعتماديات — دليل قوي
- **Master Brain**: Node.js خام، CLI + HTTP API + خادم MCP من كتالوج عمليات واحد، مصادقة PBKDF2-HMAC-SHA512، تقارير HTML/PDF/XLSX/MD/JSON بكاتب xlsx مكتوب يدوياً.
- **جسر التعاون بين الوكلاء**: سجل JSON ذرّي على المنفذ 4560 مع CLAIM/RELEASE وقناة inbox.

### 3. تنظيم عمل الوكلاء (Cursor / Claude Code / Codex / ChatGPT) — دليل قوي ونادر
- توزيع أدوار مكتوب: Cursor مدير التنفيذ، Claude Code مراجعة الكود والمعمارية، Codex وثائق وسكربتات، ChatGPT صور وصياغة.
- قالب أوامر **RCTC** (Role / Context / Task / Constraints) لكل توجيه.
- حزم تسليم (handoff zips) بلا أسرار لنقل السياق بين النماذج.

### 4. الأمان التطبيقي العملي — دليل متوسط إلى قوي
- CSP بهاش، HSTS، Origin/CSRF على كتابات المالك، تحديد معدل، مفاتيح فقط في `.env.local`، mock payments تفشل مغلقةً في الإنتاج.
- مراجعات «عدائية» بنموذج ثانٍ قبل الدمج (Hostile UI review PASS).

### 5. الذكاء الاصطناعي التطبيقي — دليل متوسط
- RAG محلي: SQLite FTS5 + FAISS + Ollama مع استشهاد برقم الصفحة (APCA SmartHelp).
- وكيل PDF للمحادثة (وثيقة) منشور بنموذج اشتراك.
- أكاديمية تعليمية بمسار تشخيص → سيناريو → تقييم أمان غير قابل للتعويض (GIZ APCA).

### 6. الخلفية المؤسسية — دليل من ملف القدرات (خارج الحزمة)
- Java 8 + Oracle: محرك استيراد إجازات بنكي مجدول مع تحقق وتراجع.
- C#، RDLC، WINCC، SQL Server (SSIS، Agent، ضبط أداء).
- أجهزة ميدانية: Miditec، ZKTeco، RFID، بصمة، QMS.
- Flutter/Dart للموبايل.

## أسلوب العمل مع الوكلاء (كيف يعمل فعلاً)

1. **مجلد لكل مشروع** فيه `project.json` + `brain.json` + `journal/` تُولَّد منها `BRAIN.md` تلقائياً.
2. **الأمر يذهب للوكيل مع سياق المشروع كاملاً** وقواعد العمل وأوامر التسجيل الواجبة بعد الإنجاز.
3. **مهمة واحدة في كل مرة**، مهلة 20 دقيقة، والوكيل الذي لا يعرف قراراً يسأل المالك (`ask_owner`) بدل التخمين.
4. **كل إنجاز يُسجَّل مع دليله**: عدد اختبارات، commit، رابط نشر، أو «لم يُنفَّذ».
5. **تقارير دورية** تُولَّد بضغطة زر وتُرسل لنموذج آخر لنقدها.

## ما يقوله عن نفسه بصدق

- كثير من المشاريع في المحفظة (نحو 35) مسجّلة بنسبة 0%: مخزون مكتشَف من الجلسات، لا إنجاز مكتمل.
- Node.js وLaravel لغتا عمل حديثتان نسبياً عنده؛ الأساس المؤسسي Java وC# وSQL.
- صيد الجوائز والـ CTF مسار جانبي لا محور توظيف.
