> ترتيب الاختيار: المشاريع ذات التقدّم المسجَّل أو السجل الحقيقي أولاً. كل «دليل» مأخوذ حرفياً من عقل المشروع أو سجل التقدّم في حزمة 2026-09-14. الأرقام بين قوسين هي نسبة الإنجاز كما سجّلتها المنصة.

## 1. ذكاء التجارة — Project1 Commerce Intelligence (83%)

**المشكلة:** اختبار جدوى تجارة إلكترونية عابرة للحدود (اكتشاف منتج → تسعير → إدراج → شراء) دون المخاطرة بمال حقيقي أو انتهاك سياسات المنصات.

**ما بُني:** منصة Next.js + PostgreSQL (Prisma) بحلقة محاكاة كاملة:
- اتصال eBay Sandbox موثَّق (`SANDBOX_VERIFIED`، Browse أعاد 3 عناصر)، إعدادات اكتشاف محفوظة (accessories / US / JO / topN=10).
- مسار CSV للعروض: معاينة → تحقق → commit، تسعير حتمي (`markupFloor` / `marginFloor`)، مسودة محلية بحالة `LOCAL_READY`، شراء محاكى بـ `dataPlane=SIMULATION`.
- **مركز جاهزية للمالك** (`/overview`, `/readiness`) يولّد المهام من فحوصات حقيقية مع دمج بـ `dedupeKey`.
- واجهة ثنائية اللغة (AR RTL / EN LTR) فاتحة/داكنة، وصفحة أوامر `/master` بقالب RCTC خلف `requireOwner`.
- مفتاح إيقاف `buyHalt=true` لا يمكن رفعه من الواجهة؛ فحوصات Origin/CSRF على كتابات المالك.

**الدليل:** Vitest 28 → 40 → 43 → 49 → 52/52 عبر الأسبوع؛ Playwright 4/4؛ `pnpm prove:csv` و`pnpm prove:readiness`؛ مراجعة واجهة عدائية بنموذج Opus: PASS بلا ثغرات رفع الإيقاف؛ مراجعة Claude Code Reviewer: PASS مع 4 ثغرات رُقّعت (G1–G4).

**الحالة:** حلقة المحاكاة مكتملة. الإيراد الحيّ محجوب بالسياسة عمداً (Production eBay معطّل، لا شراء حقيقي). مستودع خاص `kazoya/Project1`.

## 2. Master Brain + Master HQ — منصة متابعة المحفظة والتعاون بين الوكلاء (70%)

**المشكلة:** عشرات المشاريع موزّعة على جلسات Cursor وClaude وCodex بلا ذاكرة مشتركة، ولا طريقة لمعرفة ما أُنجز فعلاً وما هو ادّعاء.

**ما بُني:**
- **Master Brain** (المنفذ 4545): Node.js بلا اعتماديات. كتالوج عمليات واحد (`src/ops.js`) يُعرض بثلاث قنوات: أداة MCP، `POST /api/op/<name>`، وأمر CLI. مخزن ملفات لكل مشروع (`project.json`, `brain.json`, `journal/`)، تقارير HTML/PDF/XLSX/MD/JSON، مصادقة PBKDF2-HMAC-SHA512 (210,000 تكرار) وجلسات HMAC.
- **قناة أوامر** تشغّل `claude -p` داخل مجلد المشروع مع سياقه كاملاً، مهمة واحدة في كل مرة، مهلة 20 دقيقة، وتكتب مدخلاً في السجل عند الانتهاء. اتجاه معاكس `ask_owner` يوقف المشروع حتى يجيب المالك.
- **اكتشاف تلقائي** للمشاريع من مجلدات الجلسات (47 مشروعاً مكتشفاً من 12 جذراً).
- **Master HQ**: جسر تعاون على المنفذ 4560 بسجل JSON ذرّي بين cursor/claude/codex/chatgpt/human، مع اتفاقية CLAIM/RELEASE وتحقق حقل `to` وinbox.

**الدليل:** التقرير الذي بُني منه هذا الملف مُولَّد من المنصة نفسها (46 مشروعاً، 99 مدخل تقدّم). مراجعة Claude Code T1–T3 طُبّقت على الجسر الحي 2026-09-12.

**الحالة:** تعمل يومياً. دروس مسجّلة (مثلاً: JSON بلا BOM، مخزن واحد عبر `ACB_HOME`).

## 3. ريشة 360 — أدوار المشاهير ومركز تعاون المؤثرين (78%)

**المشكلة:** منصة مواهب ومؤثرين (Laravel backend + Next.js frontend) تحتاج دخولاً ذاتياً للمشاهير وتعديلاً مقيّداً لملفاتهم، ثم منظومة عروض واتفاقيات وصرف.

**ما بُني:**
- أدوار `celebrity/talent` مع ترحيل backfill، middleware على `public_app_roles`، `syncRoles` عند الدعوة/التفعيل، endpoint `POST celebrity-account/self/update` يرفض الحقول المحظورة. واجهة: AuthContext، قفل `CelebrityEditPage`، إصلاح فلتر `my-celebrities`.
- **Influencer Collab Hub**: ترحيلات (عروض/اتفاقيات/مهام/أدلة/محفظة/آيبان/صرف/متابعون)، لوحة `/influencer`، لوحتا إدارة (مراجعة آيبان + طلبات صرف) بصلاحيتين جديدتين، `PayoutReviewService` بآلة حالة مقفولة، auto-enroll للسفراء، 6 ملفات اختبارات Feature.
- إصلاح تفعيل الحساب (تعارض مفتاحي `invite`/`data` بين API والواجهة) ونشره.

**الدليل:** الإنتاج على Forge: BE PR #3 + FE PR #26، migration `2026_09_10_190001` Ran، commits ce79801/652d826؛ فرع `feat/influencer-collab-hub` مدفوع (86c2f81 / b5447db)؛ تشخيص إنتاجي لمستخدم بلا `ambassador_profile` وإصلاحه يدوياً.

**الحالة:** الأدوار في الإنتاج. مركز التعاون محلي بانتظار `composer install` واختبارات PHPUnit قبل PR.

## 4. المصانع — المثالية للألبان وACI للكيماويات الزراعية (85%)

**المشكلة:** مصانع أردنية بلا حضور رقمي مقنع؛ المطلوب مواقع عرض سريعة قابلة للتحسين بوكيل خارجي ثم الدمج.

**ما بُني:** موقعان Next.js عربيان: **المثالية** (صفحة مبيعات، قائمة جانبية قابلة للطي، تقييم آيزو، noindex) و**ACI** (بطل زراعي، تدرج أخضر، واتساب مبيعات). سير عمل: نسخ → إعادة علامة → ZIP تحسين لوكيل آخر → دمج → lint/build → push → Vercel.

**الدليل:** `https://al-mithaliya-dairy.vercel.app` (commit 7037dc9, Vercel READY)؛ `https://aci-agrochemicals.vercel.app`؛ GitHub `kazoya/AlMithaliya`, `kazoya/ACI`. سُجّل أيضاً عائق بصدق: انقطاع جلسة ترك ACI نسخة غير معاد علامتها قبل إكمالها لاحقاً.

**الحالة:** منشوران. أكثر من 30 مجلد مصنع آخر كمخزون غير مسجّل في المنصة.

## 5. براءة الشوبكي — متجر تجريبي فاخر لمنتجات غذائية حرفية (92%)

**المشكلة:** عميل يحتاج عرضاً مقنعاً لمنتجات زيوت وخل ومستخلصات قبل توفير أصوله (صور، شعار، أسعار).

**ما بُني:** Next.js 16 ثنائي اللغة (ar RTL افتراضي / en)، سمة «هدوء نباتي فاخر»، تحكم بالعرض، قسم تصويت/قهوة، SEO محجوب حتى `NEXT_PUBLIC_SEO_INDEX=true`. أمان: mock payments تفشل مغلقةً على `VERCEL_ENV=production`، HMAC بحد أدنى للطول، CSP بهاش، HSTS، تحديد معدل للتواصل، Supabase migration + RLS، صفحات قانونية مسودة وأدمن مقفول. إزالة تسريب `public/audio`.

**الدليل:** `https://baraahalshobaki.vercel.app`، `https://github.com/kazoya/bara-ah-alshobaki`، typecheck/unit/lint/build خضراء محلياً وعلى Vercel، تمريرا مراجعة Claude (pass-1 High مقبولة في `DECISIONS.md`، pass-2 منفّذة).

**الحالة:** بانتظار أصول العميل. قيد مكتوب: لا شهادات أو جوائز مخترَعة.

## 6. أكاديمية APCA للذكاء الاصطناعي الصناعي — مُظهِر مقترح متوافق مع أهداف GIZ (85%)

## 9. APCA SmartHelp — مساعد معرفة محلي من PDF (نواة متحققة)
