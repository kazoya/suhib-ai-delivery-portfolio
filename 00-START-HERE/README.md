# حزمة بروفايل صهيب — لوكيل بناء المحفظة المهنية

**الغرض:** ابنِ بروفايلاً مهنياً قوياً (سيرة + معرض أعمال + سرد قدرات) يعكس ما يستطيع صاحبه إنجازه فعلاً، لطلب وظيفة لائقة أو مشروع محترم.

**ما داخل الحزمة (بلا أسرار / بلا شيفرة كاملة للمشاريع):**

| مجلد | المحتوى |
|------|---------|
| `01-reports/` | تقرير محفظة كامل (MD/HTML/JSON/XLSX) + لقطة README يومية لكل العقول |
| `02-platform/` | قائمة المشاريع، سياق المنصة، العقل العام، سجل المسارات |
| `03-projects/` | لكل مشروع: `project.json` + `brain.json` + `BRAIN.md` + `journal/` + علامات التقنية |
| `04-how-tracking-works/` | كيف تعمل المتابعة، الأوامر، التقارير، الاكتشاف من جلسات Cursor/Claude/Codex |
| `05-discovery/` | ما اكتُشف من مجلدات وجلسات الوكلاء |

**ممنوع في هذه الحزمة (عمداً):** `.env`، كلمات مرور، `auth.json`، مفاتيح API، الشيفرة المصدرية الكاملة للمشاريع.

## ابدأ من هنا (للوكيل المستلم)

1. اقرأ `AGENT-PROMPT.md` كاملاً واتبعه.
2. اقرأ `01-reports/README-2026-09-14.md` ثم التقرير `report-*-all-ar.md`.
3. ركّز على المشاريع ذات التقدّم > 0 أو السجلات الغنية (انظر `02-platform/projects-list.txt`).
4. أنتج المخرجات المطلوبة في `AGENT-PROMPT.md` § المخرجات.
