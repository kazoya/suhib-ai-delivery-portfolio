# وثيقة — Wathiqa

وكيل يقرأ ملف PDF ويجيب بأسلوب محادثة واتساب.

## العرض التسويقي

1. ارفع PDF حتى **40 ميغا**.
2. اسأل الوكيل عن محتوى الملف لمدة **ساعة كاملة مجاناً**.
3. اشترك عبر **PayPal** على `innervision2016@gmail.com` من 12 دولاراً شهرياً.

## التشغيل

```bash
npm install
npm run dev
```

افتح `/try` لرفع ملف وبدء الساعة.

**الرابط الحي:** https://wathiqa-eight.vercel.app  
لا تشارك `https://wathiqa.vercel.app` — ذلك موقع آخر (سجل شهادات)، ليس هذا المنتج.

ضع `OPENAI_API_KEY` اختيارياً لإجابات أسلس مربوطة بالنص. بدون المفتاح يعمل الوكيل استخراجاً من صفحات الملف.

## الدفع

روابط الاشتراك في `/pricing` تحول إلى بايبال (`_xclick-subscriptions`).
