# GEPICO — تصور التحول الرقمي

تصور أولي مستقل لمنظومة رقمية وأتمتة لـ **مؤسسة الخليج الفنية الصناعية (GEPICO)** في الأردن، مبني بعد مراجعة الموقع العام [gepico.com](https://gepico.com/).

هذا **ليس** نظاماً رسمياً للشركة. الأرقام التشغيلية داخل المنصة **بيانات تجريبية**.

## التشغيل

```bash
cd C:\gepico
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000).

## ماذا يوجد الآن

- واجهة عربية RTL بهوية كحلية / زرقاء مستمدة من gepico.com
- الشعار والأيقونة كما نُشرا على الموقع الرسمي
- كتالوج العوائل والأصناف كما ظهرت للعامة — بما فيها التكرار والأغلاط الظاهرة
- رحلة من المواصفة والخامة إلى المختبر والمستودع والتصدير
- فرص أتمتة وذكاء اصطناعي مع بقاء القرار البشري على السعر والمواصفة والإفراج
- تقييم اكتشاف يُحفظ محلياً في المتصفح
- هاتف وبريد الشركة كما نُشرا + واتساب السيد علاء حسين (مشرف المبيعات) + رمز للمطوّر
