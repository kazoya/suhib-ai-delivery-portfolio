# RZ / الهدف الدولية — تصور رقمي للتعبئة والتغليف

تصور أولي مستقل لمنظومة رقمية وأتمتة عروض لشركة **الهدف الدولية للاستيراد والصناعة (RZ)** بعد مراجعة [rz.jo](https://www.rz.jo/) و[alhadaf-int.com](https://alhadaf-int.com/).

هذا **ليس** نظاماً رسمياً للشركة. أرقام العروض والمخزون داخل المنصة **بيانات تجريبية**. المساحة والخطوط وعدد الأصناف مأخوذة من صفحة من نحن.

ميزة أساسية في هذا التصور: **عرض سعر مقترح حسب نوع النشاط** (شاورما، كافيه، مستشفى، تموين…) يجمع الفويل والكاسات والصحون والكونتينرات — مع بقاء السعر وموعد التسليم قراراً بشرياً.

## التشغيل

```bash
cd C:\rz
npm install
npm run dev
```

ثم [http://localhost:3000](http://localhost:3000)
