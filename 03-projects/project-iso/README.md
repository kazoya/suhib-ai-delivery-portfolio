# Project ISO

رفيق دراسة عربي RTL بأسلوب مصانع المجرة/بنون (Next.js 16، shadcn/radix-nova، صدق المصدر).

## ماذا يوجد في المجلد

| ملف | الحقيقة |
|-----|---------|
| Advisera ISO 42001 LI | الكورس الحي على training.advisera.com (عداد 0.77%) |
| PECB ISO 22301 PDFs | كتيبات تسويق + أجندة، ليست كتاب 450 صفحة |
| Partner / Titanium | Aswar Akka Consultancy |

## ما لا نفعله

- تزوير شريط التقدم عبر API / seek وهمي / إكمال LearnDash بدون المشغّل
- مساعدة أثناء امتحان ProctorExam
- اختراع مفاتيح Recap رسمية
