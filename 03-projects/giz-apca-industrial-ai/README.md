# أكاديمية أبكا لمهارات وسلامة الذكاء الاصطناعي الصناعي

منصة عرض تجريبية ثنائية اللغة (عربي أولاً) لتدريب الفنيين والمدربين والمشرفين على أنظمة الذكاء الاصطناعي الصناعي — دون تحويلهم إلى علماء بيانات.

## المجلدات

| المسار | المحتوى |
|--------|---------|
| `web/` | تطبيق Next.js (المنصة الحية) |
| `execution-pack/` | حزمة التنفيذ SuperMax v1 |
| `brain.json` / `journal/` | عقل هندسي (Master Brain) |

## التشغيل

```bash
cd web
npm install
npm run dev
```

## التحقق

```bash
cd web
npm run check
```
