# بنون كيدز — تصور رقمي للمبيعات والمدارس

تصور أولي مستقل لمنصة عربية لعلامة **بنون كيدز** التابعة لـ**شركة دلتا للصناعات البلاستيكية**، بعد مراجعة [banoonkids.com](https://www.banoonkids.com/).

هذا **ليس** نظاماً رسمياً للشركة. أرقام المدارس والكراتين داخل المنصة **بيانات تجريبية**.

ميزة أساسية في هذا التصور: **مسابقة رياض ومدارس** — عدّ أغلفة واقتراح جائزة — مع بقاء إعلان الفائز قراراً بشرياً لمدير المبيعات.

## التشغيل

```bash
cd C:\Factories\Banoon
npm install
npm run dev
```

ثم [http://localhost:3000](http://localhost:3000)
