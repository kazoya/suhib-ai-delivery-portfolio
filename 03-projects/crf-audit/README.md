# CRF Audit Platform

منصة تصور رقمية عربية (RTL) لتدقيق امتثال **Cybersecurity Regulatory Framework (CRF)** لقطاع CST.

## المصدر

- `CRF Audit Form.xlsx` — الأوراق: Cover · Company's Details · Audit · Audit Result
- ورقة **Audit**: 215 ضابطاً عبر 6 مجالات مع طرق حل وأدلة مقترحة

## التشغيل

```bash
npm install
npm run dev
```

## ملاحظة صدق

تصور مستقل للعرض والاكتشاف — ليس نظاماً رسمياً لهيئة تنظيمية. حالة الامتثال تُحفظ محلياً في المتصفح وتتطلب اعتماداً بشرياً.
