# براءة الشوبكي · Bara'ah Alshobaki

Premium bilingual (ar/en) concept demo for a Jordanian artisan food brand — oils, vinegar, and botanical extracts.

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4 (tokens + custom botanical stylesheet)
- Self-hosted fonts via `next/font` (Amiri, Cormorant Garamond, IBM Plex Sans Arabic)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — redirects to `/ar`.

## Build

```bash
npm run build
npm start
```
