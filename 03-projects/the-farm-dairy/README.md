# المزرعة للألبان — تصور التحول الرقمي

تصور أولي مستقل لمنظومة رقمية وأتمتة لشركة **المزرعة للألبان** في الأردن، مبني بعد مراجعة الموقع العام [mazraadairy.com](https://mazraadairy.com/).

هذا **ليس** نظاماً رسمياً للشركة. الأرقام التشغيلية داخل المنصة **بيانات تجريبية**. حصة السوق 65٪ وردت كادّعاء على الموقع الرسمي فقط.

## التشغيل

```bash
cd C:\thefarmdairy
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000).

## ماذا يوجد الآن

- واجهة عربية RTL بهوية كريمية / خضراء مستمدة من علامة الألبان
- الشعار والأيقونة كما نُشرا على mazraadairy.com
- كتالوج المنتجات كما نُشر في `/our-products/`
- رحلة من استلام الحليب إلى التتبع والتصدير
- فرص أتمتة وذكاء اصطناعي مع بقاء القرار البشري على السعر والوصفة والإفراج
- تقييم اكتشاف يُحفظ محلياً في المتصفح
- واتساب السيد علاء حماد (مشرف المبيعات) + رمز للمطوّر
