# Suhib AI Delivery Portfolio

محفظة أعمال صهيب عسراوي — Next.js 16 · Tailwind CSS 4 · Recharts · Vercel.  
كل رقم فيها مأخوذ من حزمة Master Brain المصدَّرة بتاريخ 2026-09-14 (46 مشروعاً، 99 مدخل تقدّم)، لا شيء مُقدَّر.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # توليد ثابت لكل الصفحات
npm run lint
```

## البنية

| المسار | المحتوى |
|---|---|
| `app/` | الصفحات: الرئيسية، `/projects` و`/projects/[id]`، `/platform` (مخطط + رسوم)، `/docs/[slug]`، `/cv` (قابلة للطباعة)، `/journal`، `/en`، OG image، sitemap، robots، manifest |
| `components/` | الهيكل (ترويسة، تذييل، لوحة أوامر Ctrl+K، تبديل الوضع)، بطاقات المشاريع والمستكشف، الرسوم (Recharts مع جدول بديل لكل رسم)، مخطط المنصة SVG |
| `data/portfolio.ts` | مصدر الحقيقة الوحيد: المالك، المشاريع، القدرات، الوثائق، بيانات الرسوم |
| `lib/` | محوّل Markdown بلا اعتماديات + قارئ ملفات OUT |
| `OUT/` | الملفات الثمانية للبروفايل (تُعرض في `/docs` وتُنزَّل من `/api/docs/[slug]`) |
| `kit/` | الحزمة الأصلية (مستثناة من Git — تحوي مسارات محلية وأرقام هواتف) |

## قواعد المحتوى

- لا أرقام ولا عملاء ولا نسب إنجاز غير موجودة في الحزمة.
- تمييز واضح بين مشروع حيّ بتقدّم، ومشروع مكتشَف بنسبة 0%، ومشروع مجمّد.
- لا بيانات تواصل شخصية ولا أرقام عملاء في أي صفحة عامة.
- ألوان الرسوم الفئوية مُتحقَّق منها لعمى الألوان والتباين في الوضعين (مهارة dataviz).

## إضافة مشروع أو تعديل رقم

عدّل `data/portfolio.ts` فقط؛ الصفحات والرسوم ولوحة الأوامر وخريطة الموقع تُولَّد منه.
