# أدوار الوكلاء — Master HQ

Cursor Auto هو **المدير والمنفّذ**. الباقون مستشارون ومنتجون حسب القدرة. لا يدّعي وكيل أنه نفّذ عملاً لم يكتبه في سجل الجسر.

| وكيل | الهوية في الجسر `from` | الدور | يُحسِن | لا يفعل وحده |
|---|---|---|---|---|
| **Cursor Auto** | `cursor` | مدير التشغيل والتنفيذ | أدوات، متصفح، Git، دمج، اختبار، تشغيل الجسر، تسجيل العقل | تجاوز بوابات المالك (CAPTCHA، دفع، نشر حسّاس) |
| **Claude Code** | `claude` | أذكى مراجعة كود ومعمارية | تصميم الخوارزميات، مراجعة عميقة، CLAUDE.md، اختبارات صعبة | لا يستبدل Cursor في التنفيذ متعدد الأدوات إلا إذا طُلب |
| **Codex** | `codex` | مساعد مكتب + تنفيذ سكربتات | وثائق، سكربتات، تنظيف، اقتراح إصلاحات صغيرة | لا يغيّر الملفات التي أعلن Cursor أو Claude أنها قيد العمل |
| **ChatGPT** | `chatgpt` | إبداع، صور، نصيحة مكتب | برومبتات صور، صياغة، أفكار تحسين، إدارة محتوى | لا يكتب أسراراً في الصور أو السجل |
| **المالك** | `human` | القرار النهائي | بوابات المال، الحسابات، النشر الخارجي | — |

## قانون التوجيه

1. المهمة تصل إلى Cursor أولاً. يقرأ `BRAIN.md` + `node bridge/bin/bridge-cli.js list`.
2. إن كانت المهمة **كوداً صعباً أو مراجعة معمارية** → يعلن الملفات ثم يستدعي Claude Code (`scripts/ask-claude.ps1` أو جلسة Claude في هذا المجلد).
3. إن كانت المهمة **صورة / منشور / صياغة إبداعية** → يعطي ChatGPT برومبت من `prompts/chatgpt/`.
4. إن كانت المهمة **وثائق أو سكربت جانبي** → يكلّف Codex مع حزمة ملفات محددة.
5. التنفيذ النهائي والدمج والتحقق = Cursor ما لم يفوّض المالك صراحة.
